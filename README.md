# Лагерь у костра

Планировщик дня в духе классического фэнтези. Задачи дня становятся спутниками у костра, жизнь делится на сферы Королевства, как колесо баланса, большие цели становятся проектами внутри сфер, а просроченные задачи встают нежитью на лесной дороге. Весь день помещается на одном экране телефона, план собирается на отдельном.

Играть: https://campbyfire.github.io/. Вопросы и ошибки: [Issues](https://github.com/CampByFire/campbyfire.github.io/issues).

## Запуск

Нужен Node.js 22.12 или новее (подойдёт и 20.19+).

```
npm install
npm run dev
```

Откроется на http://localhost:5173. В консоли будет строка `Network: http://192.168.…:5173`: этот адрес открывается с телефона, если он в той же сети Wi-Fi.

- `npm test` прогоняет автотесты логики: правила, день, хранение, сохранение в GitHub.
- `npm run build` собирает сайт в `dist/`, `npm run preview` показывает собранный.
- `npm run e2e` проверяет собранный сайт в настоящем браузере, подробнее ниже.

### Автотесты экранов

В `e2e/` лежат тесты, которые проходят игру так же, как человек, в Chromium через Playwright:

- день от знакомства до отбоя: задачи добавляются, костёр разжигается, задача зовётся к огню, привал, «Готово», итоги дня и утро следующего дня. Этот тест идёт на маленьком телефоне (360×640), обычном (390×844) и компьютере (1280×800);
- запуск без сети после первого визита;
- повторяющиеся задачи;
- сохранение в GitHub с поддельным GitHub: токен перестал работать, сети нет дольше часа, срок токена подходит к концу;
- «Стереть всё» с сохранением в GitHub и без;
- доступность: проверка axe на всех экранах и листах, работа с клавиатуры в листах;
- магия: нажатия посреди заклинаний, «Вернуть» посреди награды, новый уровень, нажатие под закрывающимся листом, настройка «Магия», день от разжигания до отбоя и выполненный проект. День и эти тесты идут ещё раз на телефоне с «Уменьшить движение» в системе;
- знамя проекта: свой цвет кодом и ползунками, номера над спутниками в цвете проекта;
- Королевство: оценка сфер и колесо баланса, проект в сфере и его выполнение, напоминание оценить сферы;
- Лавка: идеи и своя награда, покупка и «Вернуть», цель и подсказка в Лагере после «Готово», правка и место на полке. Эти тесты идут на телефоне, компьютере и с «Уменьшить движение»;
- Летопись: мысль из лагеря, разделы и статьи, дневник, оформление текста, поиск и заметки в GitHub.

Тесты проверяют то, что лежит в `dist/`, поэтому сначала нужна сборка. Браузер для них скачивается один раз:

```
npx playwright install chromium
npm run build
npm run e2e
```

Если тест упал, в `test-results/` остаются снимок экрана и запись прохода. Запись открывается командой `npx playwright show-trace test-results/…/trace.zip`: в ней видно каждый шаг и страницу на нём.

Как звучит игра в VoiceOver и TalkBack, автотест не проверит. Для этого есть памятка `docs/screen-reader-check.md`, проход по ней занимает минут двадцать.

## Сайт на GitHub Pages

Сайт открыт для всех, пароля у него нет.

1. Создай репозиторий на GitHub. На бесплатном тарифе Pages работает только у публичных репозиториев.
2. Залей проект:
   ```
   git init
   git add .
   git commit -m "Лагерь у костра"
   git branch -M main
   git remote add origin https://github.com/ЛОГИН/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. Включи Pages: Settings → Pages → Source: **GitHub Actions**.
4. Запусти публикацию: Actions → «Публикация» → Run workflow (первая, что запустилась при пуше, могла упасть, пока Pages не был включён).

Дальше каждый пуш в `main` прогоняет автотесты логики, собирает сайт, проверяет его автотестами экранов и публикует по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`. Если что-то упало, на сайте остаётся прежняя версия, а что именно упало, видно в Actions в логе шага.

На телефоне сайт стоит добавить на главный экран: в Chrome меню ⋮ → «Добавить на главный экран», в Safari «Поделиться» → «На экран Домой». Игра откроется без адресной строки, а Safari не сотрёт её через неделю без визитов. На iPhone игра сама подскажет это строкой над меню.

### Что видно снаружи

Код игры, картинки и шрифты лежат на сайте открыто. Если репозиторий публичный, его код тоже может прочитать любой. Данных игроков там нет: игра каждого хранится в его браузере и в его собственном приватном репозитории.

## Работа без сети и обновления

После первого открытия игра работает без интернета: при установке service worker (`scripts/build/sw.js`) скачивает все файлы своей версии, около 2 МБ. Список файлов и номер версии вписываются при сборке.

Страница всегда сначала спрашивается у сети (если сеть не ответила за 4 секунды, открывается сохранённая), поэтому при перезапуске игрок получает свежую версию. Если приложение долго висит открытым, при возвращении в него игра проверяет обновления и показывает строку «Вышла новая версия» с кнопкой «Обновить».

Номер версии берётся из `package.json` и коммита. Его видно в Настройках и в отчёте об ошибке.

## Телефон и компьютер: сохранение в GitHub

Игра всегда хранится в браузере. Чтобы телефон и компьютер видели одну и ту же игру, её можно сохранять в свой приватный репозиторий на GitHub. Своего сервера у Лагеря нет.

1. Создай на GitHub приватный репозиторий `lager-data` (в игре есть ссылка, где название и «Private» уже выбраны).
2. В игре открой «Настройки» → «Сохранение в GitHub» → «Создай токен на GitHub». Откроется страница GitHub, где уже выбраны название, срок на год и единственное право «Contents: Read and write». В «Repository access» выбери «Only select repositories» и `lager-data`, внизу нажми «Generate token».
3. Скопируй токен (начинается с `github_pat_`), вставь в поле и нажми «Подключить». Если сохранения в репозитории ещё нет, игра запишет туда текущую игру.
4. На втором устройстве вставь тот же токен. Репозиторий найдётся сам: игра ищет `lager-data`, а если токен видит только один приватный репозиторий, берёт его. Если там в браузере ещё ничего не делали, игра просто возьмёт сохранение из GitHub.

Что лежит в репозитории:

```
game/save.json    сохранение Лагеря, его пишет игра
notes/<раздел>/…  заметки Летописи: файл на заметку, в _razdel.json название раздела, папки внутри с _papka.json
diary/<год>/…     дневник Летописи: файл на день
```

Каждая запись игры это коммит «Лагерь: сохранение (телефон)» или «(компьютер)», поэтому любую прошлую версию игры видно в истории файла `game/save.json`. Публичный репозиторий игра не примет: там лежит дневник.

Как это работает (`src/sync/`, `src/game/merge.ts`):

- После каждого действия игра через несколько секунд пишет сохранение в репозиторий, а при запуске, при возвращении в приложение и раз в две минуты смотрит, не сохранило ли что-то другое устройство.
- Если с прошлой встречи менялись обе стороны (например, телефон был без сети), версии сливаются: задачи, сферы и проекты с обеих сторон остаются, награды и покупки лавки тоже, оценки сфер за разные дни тоже, у одной задачи разные поля берутся оттуда, где их меняли, золото, опыт и итоги дня складываются. Если одно и то же поле поменяли на обоих устройствах, остаётся то, что сделано позже.
- Запись идёт с `sha` прочитанной версии файла. Если другое устройство успело записать между чтением и записью, GitHub запись не принимает (409), и игра перечитывает, сливает и пишет ещё раз. Затереть чужую запись нельзя.
- Таймер, мана и смена дня досчитываются каждым устройством одинаково, поэтому время, начатое на компьютере, на телефоне идёт дальше, а не удваивается.
- Если в репозитории другая игра, игра спросит, какую оставить. Копия из файла («Загрузить копию») уходит в GitHub целиком, без слияния.
- Без сети игра работает как обычно, сохранение догонит, когда сеть появится.

Если сохранение не доходит до GitHub:

- Когда запись в GitHub не проходит (например, GitHub больше не принимает токен) или в репозитории ждёт другая игра, в верхней полосе лагеря появляется значок. Он открывает «Сохранение в GitHub», где сказано, что случилось и что сделать.
- Когда сети нет дольше часа, значок спокойнее: игра хранится в браузере и догонит GitHub сама.
- Срок токена игра узнаёт от GitHub, а если браузер его не видит, считает год от подключения. Его можно поправить в том же листе. За две недели до конца над меню появляется напоминание с кнопкой «Заменить».
- «Заменить токен» в листе «Сохранение в GitHub» принимает новый токен того же аккаунта GitHub, который видит тот же репозиторий. Репозиторий и игра остаются прежними.

Про безопасность:

- Приватный репозиторий видишь только ты и те, кого ты сам туда пригласишь.
- Токену доступен только выбранный репозиторий и только его файлы: ни других репозиториев, ни настроек аккаунта он не видит.
- Токен хранится только в браузере этого устройства и в копию сохранения не попадает. Пароля у него нет, поэтому на чужом компьютере GitHub лучше не подключать. Если устройство потерялось, токен отзывают на странице github.com/settings/personal-access-tokens.
- Все сайты одного аккаунта на `ЛОГИН.github.io` живут на одном адресе и видят хранилище друг друга. Не публикуй рядом чужой код, которому не доверяешь.

## Летопись: дневник, свои разделы и заметки

Во вкладке «Летопись» есть дневник, а ещё можно завести свои разделы, например «Идеи» или «Статьи», и записывать туда что угодно. Золота и опыта за заметки нет, герой только отвечает «Записал, не потеряется».

- **Дневник.** Пишешь в поле «Как прошёл день?», запись встаёт в сегодняшний день со временем. Над полем можно дать записи название, его можно и не писать. Дни идут списком, новые сверху; рядом с датой видно, сколько в тот день сделано в игре. Запись можно поправить или удалить. День игровой: запись в час ночи попадает во вчерашний день.
- **Метки в дневнике.** Слово с решёткой в тексте или названии записи это метка: `#работа`, `#сны`, `#идеи_на_потом`. Метки, которые уже есть, стоят кнопками под полем записи: нажатие дописывает метку в конец текста. Над днями ряд «Метки»: «Все» и каждая метка с числом записей, частые первыми. Выбранная метка оставляет только свои записи, а дни без них прячутся. Метка это просто текст записи, поэтому в файле дня ничего нового нет, а поиск находит и `#сны`. Цвет вида `#ff8800`, решётка в ссылке и заголовок `# …` метками не считаются.
- **Записать мысль.** Кнопка у костра и наверху Летописи открывает поле и выбор: дневник или раздел. По умолчанию мысль идёт туда, куда писали в прошлый раз. В первый раз сразу предлагается раздел «Идеи».
- **Раздел.** У раздела есть название, значок и вид. Лента: одно поле, запись в одно нажатие, новые сверху. Статьи: у каждой заметки заголовок и длинный текст. Раздел можно переименовать и удалить (значок карандаша в разделе).
- **Папки.** Внутри раздела можно завести папки, а в них свои папки, сколько угодно вглубь (значок папки с плюсом наверху раздела). Папки стоят над заметками, рядом видно, сколько в каждой заметок вместе с вложенными. Вверху папки кнопка назад к той, где она лежит, а глубже первого уровня ещё и путь до неё; системная «Назад» поднимается на одну папку. В листе заметки «Перенести в папку…» отправляет её в любую папку того же раздела, внизу появится «Вернуть». Карандаш в папке открывает её настройки: название, «Перенести папку…» (со всем, что в ней) и удаление. Непустую папку можно удалить двумя способами: всё из неё поднимается на уровень выше, или она удаляется вместе с заметками (тогда игра переспросит).
- **Последние дни.** Сделанное за две недели теперь лежит в Летописи отдельным разделом «из игры».
- **Оформление.** В листе заметки, статьи или записи дневника над текстом панель, она видна, пока курсор в поле, и стоит у верха листа: жирный, курсив, подчёркнутый, зачёркнутый, подзаголовок, сворачивание раздела, списки, цитата, цвет текста и «✕ стиль», который снимает оформление. Цвет берётся из набора или свой (кружок «+» или код вроде `#ff8800`), последние свои цвета запоминаются. Под полем счётчик знаков и «Развернуть поле». Текст в файле остаётся Markdown, цвет пишется как в Obsidian: `<span style="color:#ef6b5e">текст</span>`, подчёркнутый как `<u>текст</u>`. GitHub цвет не показывает, но текст виден.
- **Разделы.** Подзаголовок начинает раздел: стрелка слева от него или кнопка на панели сворачивает текст до следующего заголовка. Свёрнутый заголовок в файле выглядит так: `### Заголовок <!-- свёрнуто -->`, и пометку видно только при правке файла руками. При чтении статьи разделы сворачиваются нажатием на заголовок, в файл это не пишется. Вставка из буфера идёт простым текстом.
- **Черновики.** Набранное в статье или заметке остаётся черновиком на этом устройстве, даже если лист закрылся. В GitHub он не уходит: туда текст идёт только по кнопке «Сохранить». В разделе черновик виден строкой «Несохранённый черновик», в списке статей и в поиске его нет. Чтобы выбросить черновик, сотри его текст или верни прежний.
- **Статьи** открываются для чтения, править их можно кнопкой «Править». Карточки ленты и дневника показывают текст с оформлением.
- **Поиск.** Поле «Найти в Летописи» ищет по всем разделам с их папками и по дневнику, без учёта регистра и «ё». У найденной заметки из папки видно и раздел, и папку: «Идеи · Проекты».

Как это лежит в GitHub (`src/notes/`):

```
diary/2026/2026-11-04.md                день дневника: записи «## 08:12 Название» и текст под ними
notes/idei/_razdel.json                 {"title": "Идеи", "icon": "bulb", "vid": "lenta"}
notes/idei/2026-11-04-0812.md           запись ленты: имя из даты и времени
notes/stati/kak-ya-planiruyu-den.md     статья: имя из заголовка, первая строка «# Заголовок»
notes/idei/proekty/_papka.json          папка внутри раздела: {"title": "Проекты"}
notes/idei/proekty/sad/2026-11-05-0930.md   запись в папке внутри папки
```

- Каждая заметка это обычный Markdown-файл, его можно открыть и поправить прямо на GitHub. Папку, созданную руками в `notes/`, игра покажет разделом, а папку внутри раздела покажет папкой (без `_papka.json` её название это имя папки). Переименование папки правит только `_papka.json`. Перенос заметки или папки в GitHub выглядит как новые файлы и удаление старых: переноса файлов в его API нет. Если заметку перенесли на одном устройстве, а на другом в это время поправили, останутся обе: поправленная на старом месте, перенесённая на новом.
- Заметки живут отдельно от `game/save.json`: сохранение игры от них не растёт, и правка заметки на одном устройстве не спорит с игрой на другом.
- Пока GitHub не подключён, заметки хранятся только в этом браузере (`taskcraft-lager-notes` в `localStorage`). При подключении они уходят в репозиторий.
- После правки заметка уходит в GitHub через пару секунд отдельным коммитом («Лагерь: новая заметка (телефон)»). Новое с другого устройства приходит при запуске, при возвращении в приложение и раз в две минуты. Скачиваются только изменённые файлы.
- Без сети заметки ждут в браузере и уходят, когда сеть вернётся. Внизу Летописи видно, сколько ещё не в GitHub.
- Если одну заметку поменяли на двух устройствах, версия из GitHub остаётся на месте, а своя ложится рядом отдельной заметкой с припиской `-s-telefona` или `-s-kompyutera`. Ничего не теряется.
- В один день дневника пишут с обоих устройств, поэтому день сливается по записям: новые записи с обеих сторон остаются, удалённая или поправленная на одном устройстве запись не возвращается со второго. Текст в файле дня, написанный руками без «## время», тоже виден, отдельной записью без времени и без названия. Файл дня без папки года (`diary/2026-11-04.md`) читается так же.
- Удалённая заметка или раздел пропадает из папки, но остаётся в истории репозитория.
- «Стереть всё» убирает заметки из этого браузера. В GitHub они остаются, даже если вместе с игрой удаляется и сохранение.

## Сохранение в браузере

- Игра пишется в `localStorage` после каждого действия и раз в 15 секунд. Если браузер не дал записать (кончилось место, приватный режим), над меню появляется предупреждение с кнопкой «Копия».
- Если сохранение не читается (повреждено или записано более новой версией игры), игра ничего поверх него не пишет: откладывает его в `taskcraft-lager-v1.broken` и показывает экран, где можно скачать его, взять игру из GitHub, загрузить копию из файла или начать заново.
- Формат сохранения имеет номер (`SAVE_VERSION` в `src/game/store.ts`). Когда меняется устройство `State`, номер растёт на один, а в `MIGRATIONS` добавляется переход со старого формата: старые сохранения доводятся до нового при загрузке.
- Если GitHub не подключён, раз в неделю игра напоминает сохранить копию в файл.
- Если действие упало с ошибкой, недоделанное действие не сохраняется: игра возвращается к последней записи и показывает экран «Что-то сломалось» с отчётом для разработчика. Кнопка «Сообщить о проблеме» открывает новую запись в Issues репозитория, куда отчёт уже вставлен (`ISSUES_URL` в `src/ui/report.ts`).
- Настройки → «Стереть игру…» убирает из этого браузера игру, заметки и токен GitHub, а по желанию и сохранение в GitHub: удаляется только файл `game/save.json`, репозиторий, заметки, дневник и история остаются. Сначала лист предлагает скачать копию в файл. Если сохранение должно уйти тоже, а GitHub не ответил, не стирается ничего.

## Правила

- **Спутники.** Каждая задача становится спутником одного из четырёх классов, по размеру: I разбойник (до получаса), II варвар (пара часов), III маг (целый день), IV рыцарь (несколько дней). Класс подбирается по оценке времени, его можно поправить при сдаче. У каждого класса три облика с разным снаряжением, облик у задачи свой и не меняется. Плащ спутника покрашен в цвет похода, у задачи без похода плащ обычный.
- **Утро.** На экране «План» собираешь отряд на день и разжигаешь костёр: +3 опыта за каждого позванного, но не больше чем за 5. Собирать план не обязательно: вверху сбора отряда «Сразу к огню» разжигает костёр с теми, кто уже у костра, а «Быстрый сбор» сначала возвращает дела, которые вчерашний отбой отправил в отряд.
- **День.** Позванный к огню спутник работает, таймер идёт в задачу. «Готово» даёт 25 золота за уровень и опыт (25, 40, 60, 85 по уровням), а проекту прогресс, равный уровню.
- **Шторка задач дня.** Под сценой Лагеря видно столько задач, сколько помещается. Шторку можно вытянуть вверх пальцем, нажать на её ручку или на «Ещё N в плане дня», и она поднимется поверх сцены со всеми задачами дня, их можно листать и открывать. Вниз её возвращают пальцем, ручкой, нажатием на сцену или кнопкой «Назад». «N сделано» показывает сделанные сегодня задачи внизу шторки, приглушёнными, второе нажатие их прячет.
- **Мана.** Мана показывает силы героя. Утром её 100. Работа тратит 15 в час, привал возвращает 30 в час, задача из другой сферы стоит 5 (сфера и её проекты считаются одним делом). Вечером или в выходной, если сегодня уже была работа, раз в день можно взять второе дыхание: +30.
- **Смены.** Утро, рабочий день, вечер, выходной и ночь (за 30 минут до отбоя). Днём на первом месте рабочие сферы и их проекты, вечером и в выходной личные. Распорядок меняется в Настройках.
- **Искра и угольки.** Начать уже победа. 2 минуты у огня подряд зажигают искру: +5 опыта, раз в день за задачу. Дальше каждые 15 минут работы приносят уголёк: +2 опыта, не дожидаясь «Готово».
- **Нежить.** Задача с прошедшим сроком встаёт нежитью на лесной дороге: сначала скелет-миньон, с 7-го дня старый скелет. Страшнее она не становится, а выгоднее да: за упокоенную нежить опыта на половину больше, за старую вдвое. У нежити три равных решения: «Упокоить» зовёт её к огню, «Перенести» даёт новый срок (завтра, через неделю или без срока), «Отпустить» отпускает на покой. Перенести и отпустить тоже приносит опыт: +5, а «Вернуть» после «Отпустить» его забирает. Если нежити больше, чем мест на дороге, дальний конец дороги тонет в тумане, без счёта.
- **Когда начну.** У задачи можно записать, когда начать и с какого крошечного шага: «Когда налью чай, открою документ». Лагерь показывает эту строку, пока задача ждёт у огня, и кладёт её в напоминание календаря. У повторяющейся задачи строка переходит в каждую пришедшую.
- **Календарь.** Месяц сеткой и всё, что стоит на выбранный день: события, задачи, позванные на этот день, сроки задач и повторы. Нажатие на день открывает его шкалой по часам: сверху «Весь день», ниже дела блоками по времени, накладки встают рядом, сегодня видна линия «сейчас», нажатие на пустой час заводит событие. Дело на шкале можно перетащить на другое время, как в Google Календаре: мышью сразу, пальцем после долгого нажатия (короткое движение пальцем листает шкалу), время встаёт на шаг в 15 минут, длина дела не меняется, а «Вернуть» отменяет перенос. С клавиатуры то же делает Alt со стрелкой вверх или вниз. Если событие повторяется, Лагерь спрашивает: перенести только этот день (он становится отдельным событием, а в серии пропускается) или все дни серии. Повторяющаяся задача переезжает на новое время целиком. Дни листаются стрелками и смахиванием. Строка «Завтра 1 событие и 2 задачи, с 10:00» в «Сборе отряда» и кнопка над задачами в Лагере (на ней сегодня час ближайшего события) открывают день сразу по часам. Событие (`Meeting` в `State.meetings`) это не задача: к костру оно не идёт, опыта не даёт, нежитью не становится и на следующий день не переезжает. У него день, время начала и конца (без времени оно на весь день), место и цвет: один из тех же шести, что у сфер и проектов, или свой, кодом и ползунками. Событие может повторяться: каждый день, по будням (с понедельника по пятницу), каждую неделю, каждые 2 недели, каждый месяц или каждый год, с необязательной датой окончания. Если в месяце нет нужного числа, событие с 31-го встаёт на его последний день, а с 29 февраля на 28-е. Серия это одна запись (`repeat`, `repeatUntil`, `skip`), дни считаются на лету. Правка и удаление меняют всю серию, а один день можно пропустить, и его можно вернуть. Событие пишется одной фразой: «завтра в 10 стоматолог». События сегодняшнего дня стоят в плане дня отдельным разделом и попадают в файл напоминаний с будильником за 30 минут (серия попадает туда правилом повтора, с пропусками и датой окончания), а события на весь день напоминают накануне в 18:00. Логика в `src/game/calendar.ts`.
- **Напоминания.** Своего сервера нет, поэтому звонит календарь телефона. Настройки → «Напоминания» скачивают файл `lager.ics`: утренний костёр (по рабочим дням или каждый день, время выбирается) и задачи со временем на сегодня и дальше, повторяющиеся тоже, с будильником за 10 минут. У событий постоянные id, поэтому календари, которые это умеют, обновляют их при новом импорте, а не дублируют. Если задачи со временем поменялись, файл скачивают заново. Выбор помнит устройство, в сохранение он не идёт. Собирает файл `src/game/ics.ts`.
- **Лавка.** Золото за «Готово» меняется на радости в жизни. Лавка открывается нажатием на золото в верхней полосе Лагеря (и из Настроек, под уровнем героя). Награды ты заводишь сам: название и цена от 5 до 99 995 золота, шагом 5. Под ценой лавка подсказывает, сколько это в делах: по твоему темпу за последние 14 дней с делами («примерно 2 дня дел»), а пока таких дней меньше трёх, в коротких задачах. Есть готовые идеи четырёх размеров, от «Чашки любимого чая» за 60 до «Выходного только для себя» за 5 000: нажатие ставит идею на полку, название и цену потом можно поменять. Когда золота хватает, у награды появляется «Купить»; когда нет, видно, сколько не хватает, и полоска. Покупка сразу забирает золото и ложится в «Куплено» с названием и ценой на тот момент, одну награду можно покупать сколько угодно раз. «Вернуть» есть в сообщении сразу после покупки и у сегодняшних покупок в истории. На одну награду можно копить: цель стоит наверху лавки с полоской, а в Лагере после каждого «Готово» видно «До «…» осталось N золота» или «Теперь хватает на «…»» с кнопкой «В лавку». Купленная цель перестаёт быть целью. Штрафов нет, золото не сгорает. Если одно и то же золото потратили на двух устройствах без связи или вернули уже потраченное «Готово», золото уходит в минус и возвращается с новыми делами. Логика в `src/game/shop.ts`.
- **Возвращение.** Если в лагерь не заглядывали 2 дня и дольше (по действиям игрока, а не по открытию), его встречает «Костёр ждал». Пропуски не считаются. Герой отдохнул: первые 3 дела в этот день дают вдвое больше опыта, сколько бы ни длился перерыв. Нежить можно отпустить на покой разом (сроки снимаются, «Вернуть» их возвращает), а утренний сбор в этот день по желанию: «Сразу к огню» разжигает костёр с тем, что уже в плане.
- **Сферы и проекты.** Королевство делится на сферы жизни, как колесо баланса: в новой игре это Работа, Здоровье, Дом и быт, Финансы, Семья и отношения, Друзья, Развитие и Отдых, их можно переименовать, убрать и добавить свои. Сфера не кончается, у неё есть тип: рабочая (в полной силе днём в будни), личная (вечером и в выходные) или в любое время. Время от времени каждую сферу оценивают от 1 до 10, и Королевство рисует колесо, где бледным контуром видна прошлая оценка. Напоминание приходит раз в месяц (в Настройках можно раз в неделю, раз в квартал или не напоминать), в новой игре первый раз через три дня. Большая цель из многих задач это проект в сфере, он живёт по её типу. Когда игрок решит, что проект выполнен, он отмечает это кнопкой: знамя уходит в зал трофеев, а незаконченные задачи переходят в сферу. Из зала трофеев проект можно вернуть в работу.
- **Вестник.** Задача без сферы, без дня и без горизонта приходит к вестнику письмом. Письма разбирают в сборе отряда: задаче выбирают сферу или проект и зовут её на сегодня или в отряд.
- **Горизонты.** Задачу можно поставить на неделю, месяц, квартал или год. В сборе отряда у каждого горизонта своя вкладка рядом с «Днём»: задачи периода, сколько из них сделано, свёрнутые задачи меньших периодов внутри, стрелки к соседним периодам. Неделя считается с понедельника, а неделя на стыке месяцев относится к месяцу своего четверга. Не сделанная за период задача нежитью не становится: она остаётся хвостом, и в сборе отряда её переносят в нынешний период, в период побольше или отпускают.
- **Задача одной фразой.** В новой задаче можно написать всё сразу: «завтра в 19:00 позвонить маме», «отчёт до пятницы на 2 часа #работа», «Добавь задачу на неделю "Съесть мороженое"». Игра без всякого ИИ ищет знакомые слова: день («сегодня», «завтра», «в пятницу», «через 3 дня», «20 ноября»), срок («до пятницы», «к 15.11», «до конца месяца»), время («в 19:00», «в 8 вечера»), оценку («на полчаса», «на 2 часа», «на весь день»), горизонт («на неделю», «в декабре», «в первом квартале», «на год») и сферу или проект («#работа», «в сферу Здоровье», «в проект Ремонт»). Что узнано, видно под полем. Выбранное руками сильнее фразы, а название в кавычках берётся как есть. Словарь лежит в `src/game/phrase.ts`.
- **Повторяющиеся задачи.** Задача может повторяться каждый день, раз в неделю или в любые дни недели на твой выбор. В свои дни она сама встаёт в план. Пока прошлая не сделана, новая не приходит, а отпущенная вернётся в следующий свой день. В прогресс проекта повторяющиеся задачи не идут: они не кончаются.
- **Отпустить.** Задача уходит без награды и без штрафа. Сразу после этого её можно вернуть кнопкой «Вернуть» в сообщении внизу, позже в Королевстве → «Отпущенные».
- **Забытый таймер.** Если 90 минут не заглядывать в игру, таймер встанет сам и спросит, шла ли работа.
- **Отбой.** Перед отбоем лагерь подводит итоги дня: отмеченные задачи остаются у костра на завтра, остальные возвращаются в отряд. Игровой день начинается в 4 утра, поэтому работа после полуночи идёт в тот же день.

Все числа лежат в `src/game/rules.ts`.

## Магия

Анимации в духе волшебства. Игра меняется сразу, магия только догоняет её светом: ни одна кнопка не ждёт конца заклинания, а новое заклинание гасит хвост прежнего за 0,16 секунды. Ошибка внутри магии пишется в консоль и не роняет игру.

- Настройки → «Магия»: «Вся», «Спокойная» (без частиц, полётов и сдвигов, только мягкий наплыв) или «Без анимаций». Пока ничего не выбрано, решает система: при «Уменьшить движение» магия спокойная. Выбор лежит в настройках устройства (`taskcraft-lager-device`) и в сохранение игры не попадает.
- Слои магии поверх приложения не ловят нажатий и скрыты от экранного диктора. Числа наверху (золото, уровень, мана) магия только на время показывает прежними, пока до них летят монеты и звёзды, а настоящее значение всегда в разметке.
- Что есть: искра под пальцем, листы, смена разделов, цена смены похода, «Позвать к огню», «Готово», привал, новый уровень, искры над костром и светлячки ночью, живая поляна (отряд дышит, языки пламени и дымок, тени облаков днём, фонарь в сумерках); разжигание тлеющего лагеря, нежить встаёт и упокаивается, письмо вестника, новый спутник, «Отпустить» и «Вернуть», Второе дыхание, вечер и ночь наплывом, отбой, выполненный проект, покупка в лавке и печать на странице пароля.

## Картинки лагеря

Лагерь нарисован заранее: 3D-сцена из моделей KayKit снимается в картинки для дня, вечера и ночи, а каждая фигура на каждом месте отдельной картинкой с прозрачным фоном. Плащ каждого героя снят ещё и отдельным белым слоем: приложение красит его в цвет похода. На телефоне нет 3D, поэтому всё работает быстро и не сажает батарею.

Переснять (нужен git и Chrome или Edge):

```
cd scripts/render-camp
npm install
npm run models     # скачивает модели KayKit в kaykit/
npm run preview    # три пробных кадра в out/
npm run render     # картинки в public/camp/ и src/scene/camp.json
npm run icons      # значки приложения из ночного костра
```

Камера, свет, места и позы задаются в `scripts/render-camp/scene/camp.js`.
